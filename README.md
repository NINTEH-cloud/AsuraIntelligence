# Asura Intelligence

An all-in-one planner for Guild Wars 2, as a [Raidcore Nexus](https://raidcore.gg/Nexus) addon.

## What's inside

- **Account**: wallet, raids and weekly progress at a glance.
- **Meta events**: timeline overlay, tracked events and alerts when an event starts.
- **Wizard's Vault**: objectives with an overlay and waypoints.
- **Legendary planner and Goals**: what you still need, based on your own account.
- **Achievements and Story**: progress, watch list and guides on the map.
- **Map**: map completion with a route to the next point.
- **Gathering**: routes along ore, wood and plant nodes from your marker packs.
- **Trading Post, Item search, Recipes, Mystic Crafting, Builds and Farming route**.
- **Mounts**: radial menus for mounts and other actions such as the skiff, fishing and the homestead.
- **Pathing**: shows TacO/Blish marker packs in the world, on the map and on the minimap.

The addon is available in Dutch, English and German.

## Requirements

- A Guild Wars 2 API key with the permissions account, progression, inventories, characters, wallet, unlocks, builds and tradingpost. Create one at [account.arena.net/applications](https://account.arena.net/applications).
- Your API key (and an optional DeepL key) is only stored locally in the addon's `settings.json`. It is never sent anywhere except to the official GW2 API (and DeepL).

## Installation

1. Install [Raidcore Nexus](https://raidcore.gg/Nexus).
2. Download `AsuraIntelligence.dll` from the [latest release](https://github.com/NINTEH-cloud/AsuraIntelligence/releases/latest).
3. Put it in `Guild Wars 2/addons/` and load it in the Nexus addon library.

Updates arrive automatically through Nexus.

## Reporting a bug or idea

Open an [issue](https://github.com/NINTEH-cloud/AsuraIntelligence/issues), or use the **Report a bug** button in the addon's settings. A screenshot and your addon version (shown in the settings) help a lot.

## Fair play

The addon does not read or change game memory and does not automate gameplay. Every key it sends is a single press that you trigger yourself, never a macro.
